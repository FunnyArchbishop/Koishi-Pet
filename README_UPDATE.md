## 二、各迭代详情

### 迭代 1 — 地面软阴影 + 待机呼吸浮动

- 宠物脚下绘制**径向渐变软阴影**，让角色看起来"接地"，更有立体感。
- 空闲 / 坐下 / 睡眠时，精灵会做 ±2px 的**正弦呼吸浮动**，不再死板。
- 阴影会随呼吸幅度轻微缩放，落地时阴影更明显。

> 实现位置：`PetWindow::drawShadow()`、`PetWindow::paintEvent()`。

---

### 迭代 2 — 飘浮爱心粒子系统

- 新增 `HeartParticle` 粒子结构，爱心从角色头顶飘起、左右摇摆、逐渐淡出。
- 触发时机：
  - 单击 → 冒出 3 颗爱心
  - 触发特殊动画 → 冒出 5 颗爱心
  - 悬停抚摸 → 每 1.5s 冒 1 颗
  - 达成里程碑 → 冒出 5 颗爱心

> 实现位置：`spawnHearts()` / `updateHearts()` / `drawHearts()`。

---

### 迭代 3 — 悬停抚摸

- 鼠标**悬停在宠物身上**时，每 1.5 秒：
  - 好感度 +1（有上限）
  - 飘出 1 颗爱心
- 让"摸摸头"变成真实的互动，而不再只能点击。

> 实现位置：`enterEvent()` / `leaveEvent()` + `onTimerTick()` 中的悬停判定，常量 `HOVER_PET_MS`。

---

### 迭代 4 — 飞行倾斜 + 落地压缩

- **空中倾斜**：被甩飞 / 跳跃时，精灵按水平速度倾斜（约 ±17°），更有"飞出去"的感觉。
- **落地压缩**：重重落地时精灵在垂直方向被压扁、水平方向拉宽，随后快速回弹（squash & stretch）。
- 动效围绕**脚底中心**旋转缩放，避免角色"漂移"。

> 实现位置：`paintEvent()` 中的 QTransform + `physicsStep()` 落地判定，`m_squash` 衰减。

---

### 迭代 5 — 点击穿透（幽灵模式）

- 开启后窗口设置 `Qt::WindowTransparentForInput`，**鼠标点击会穿透到下方窗口**，完全不挡工作。
- 由于此时无法点击宠物本体，可从**托盘右键菜单**或**行为设置**里关闭。
- 开关会持久化保存。

> 实现位置：`onToggleClickThrough()`、`Qt::WindowTransparentForInput`。

---

### 迭代 6 — 换装 / 换色

- 无需额外素材，用 QPainter 合成方式给精灵**程序化着色**（剪影染色 + 保留细节）。
- 预设 7 种配色：原色、粉红、天蓝、紫色、森绿、橙金、冰蓝。
- 着色作用于 PNG 与 GIF 当前帧，选择后即时生效并持久化。

> 实现位置：`paintEvent()` 中的着色合成 + `onTintAction()`。

---

### 迭代 7 — 设置对话框

- 右键菜单新增「设置…」，弹出一个统一设置面板，包含：
  - **大小**滑块（100–400 px）
  - **行走速度**滑块（60–160 px/s）
  - **透明度**滑块（20%–100%）
  - **开关**：自动行走 / 物理重力 / 窗口置顶 / 点击穿透 / 音效
  - **好感度进度条**（♥ 好感度 x/100）
- 点 OK 后一次性应用并保存，宠物中心位置保持不变。

> 实现位置：`onOpenSettings()`。行走速度由 `m_walkSpeed` 控制并持久化。

---

### 迭代 8 — 统计与成就

- 记录并持久化：
  - 点击次数
  - 抚摸次数
  - 特效触发次数
  - 陪伴时长（在线累积）
- 右键菜单「统计信息」以对话框展示上述数据。
- **里程碑台词**：点击或抚摸达到 10 / 50 / 100 / 500 / 1000 / 5000 次时，恋恋会冒出专属台词 + 爱心（如"一千次…你…真的不会忘记我吗…"）。

> 实现位置：`statsText()` / `checkMilestones()` / `onShowStats()` + `achievementDialogue()`（在 `pet_state.h`）。

---

### 迭代 9 — 多皮肤系统

- 自动扫描 `assets/skins/*/` 目录，凡含图片的目录即视为一套皮肤。
- 右键菜单「皮肤」列出「默认」+ 所有检测到的皮肤，一键切换。
- 皮肤目录内缺的素材会**自动回退到默认素材**（例如皮肤没有 GIF 时，GIF 模式仍可用）。
- 新增 `generate_skins.py` 脚本，可一键生成 `pink` / `blue` / `gold` 三套示例皮肤（需 Python + Pillow）。

> 实现位置：`loadSprites()`（带回退）/ `availableSkins()` / `onSkinAction()`。

#### 自定义皮肤方法

1. 在 `assets/skins/` 下新建目录，如 `assets/skins/my_koishi/`。
2. 放入同名素材（可只放部分，缺的会自动回退默认）：
   ```
   sprite_idle.png / .gif
   sprite_blink.png / .gif
   sprite_walk1.png / .gif
   sprite_walk2.png / .gif
   sprite_sit.png / .gif
   stand.gif
   creep.gif
   triggers/*.png / .gif
   ```
3. 重新运行程序，右键 → 皮肤 → 选择你的皮肤。

---

### 迭代 10 — 音效 + 自动保存打磨

- 新增**音效开关**（默认关闭）：开启后点击、触发特效、达成里程碑时播放系统提示音（`QApplication::beep()`）。
- 新增**每 60 秒自动保存**：陪伴时长、统计、位置等不再只依赖退出时保存，异常退出也不易丢失。

> 实现位置：`playBeep()` / `onToggleSound()` / `onTimerTick()` 中的自动保存。

## 五、构建与运行

```bash
# 生成示例皮肤（可选，需要 Python + Pillow）
python generate_skins.py

# 构建（Ninja 或 MinGW Makefiles 均可）
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH="<Qt6路径>" -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 运行
build\KoishiPet.exe    # Windows
./build/KoishiPet      # Linux / macOS
```

> 说明：本项目在 `D:/msys64/mingw64`（GCC + Qt6）环境下验证；本会话沙箱下 Ninja 会卡死，故实际使用 `MinGW Makefiles` 生成器完成构建。
