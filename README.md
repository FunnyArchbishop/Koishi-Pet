# DeskPet Qt — 古明地恋桌面宠物

基于 **Qt6** 的桌宠应用，以东方 Project 角色**古明地恋**为主题。纯 Qt 库，无原生 API 依赖。

## 特性

- 透明置顶无边框窗口，始终可见
- 支持 **PNG 多帧精灵** 和 **GIF 动画** 两种模式，右键切换
- 动画状态：空闲（眨眼）、行走、坐下、睡眠、特殊触发
- **快速点击**显示好感度对话气泡 / **按住拖拽**移动位置 / **甩出**带惯性飞出去
- **悬停抚摸**：鼠标悬停即可增加好感度并冒出爱心
- **物理系统**：重力、落地（站在任务栏上）、跳跃、撞墙反弹、甩动惯性（可在菜单开关）
- **视觉动效**：地面软阴影、待机呼吸浮动、飞行倾斜、落地压缩、飘浮爱心粒子
- **睡眠模式**：长时间不理会后恋恋会坐下打盹（Zzz…），点击即可唤醒
- **随机闲聊**：发呆时会时不时冒出一句恋恋的台词（16 句台词池）
- **时段问候**：每个小时第一次点击时，恋恋会按时间说「早上好 / 午安 / 晚上好 / 夜深了」
- **今日运势**：右键抽签（每天固定一支），大吉/中吉/小吉/吉/末吉/凶/大凶/恋恋吉 + 专属寄语
- **东方幻存神签**：右键弹窗显示官方御神签图片（角色名 + 运势，每天一支），需先运行 `crawl_omikuji.py` 爬取
- **连击戳戳**：800ms 内快速点击 3 次，触发「被戳晕了」的可爱反应 + 爱心星星雨
- **换装换色**：7 种配色预设，无需额外素材
- **多皮肤**：从 `assets/skins/*/` 自动加载，一键切换
- **统计与成就**：点击/抚摸/特效次数、陪伴时长、里程碑专属台词
- **双击**触发随机特殊动画
- **点击穿透（幽灵模式）**：不挡鼠标，方便边工作边看
- **系统托盘**：隐藏/显示、点击穿透、退出
- **统一设置对话框**：大小/速度/透明度滑块 + 开关 + 好感度进度条
- **音效**：点击/特效/里程碑提示音（可开关）
- **持久化设置 + 每 60s 自动保存**：位置、大小、模式、速度、好感度、透明度、换装、皮肤、开关、统计全部自动记住
- 右键菜单可调整大小（100 / 150 / 200 / 300 / 400）与透明度（20%–100%）
- 好感度系统：每分钟自动 +5，20/40/60/80/100 解锁古明地恋专属对话
- 自动随机行走 + 屏幕边界弹跳（支持多显示器）

## 快速开始

### 前置要求
- CMake 3.16+
- Qt6 (Widgets 模块)
- GCC / MSVC (C++17)

### 构建
```bash
# Ninja 或 MinGW Makefiles 均可
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH="<Qt6路径>" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### 运行
```bash
./build/KoishiPet            # Linux / macOS
build\KoishiPet.exe          # Windows
```

## 操作方式

| 操作 | 效果 |
|---|---|
| **快速点击** | 显示好感度对话气泡（3秒消失），唤醒睡眠 |
| **按住拖拽** | 移动宠物位置 |
| **快速甩出** | 松手后宠物带着惯性飞出，撞墙反弹 |
| **悬停** | 抚摸：每 1.5s 增加好感度并冒出爱心 |
| **快速连击** | 800ms 内连点 3 次 → 「被戳晕了」反应 + 爱心星星雨 |
| **双击** | 随机触发一个特殊动画 |
| **右键** | 菜单：特殊动画 / 皮肤 / 模式切换 / 大小 / 换装换色 / 透明度 / 行为开关 / 好感度 / 今日运势 / 幻存神签 / 统计 / 设置 / 复位 / 退出 |
| **托盘图标（右下角控制面板）** | 右键：显示/隐藏、自动行走、重力、置顶、点击穿透、音效、退出；单击/双击：点击穿透时自动关闭穿透并找回宠物，否则切换显示/隐藏 |

## 行为设置（右键 → 行为设置）

| 开关 | 说明 |
|---|---|
| **自动行走** | 关闭后恋恋只发呆/坐下，不再随机走动 |
| **物理重力** | 开启时恋恋会落到任务栏上行走、跳跃；关闭后恢复自由漫游 |
| **窗口置顶** | 关闭后恋恋不再始终保持在最前 |
| **点击穿透（幽灵）** | 开启后鼠标点击穿透到下方窗口，完全不挡工作；开启时会弹出托盘气泡提示，单击/双击托盘图标即可关闭并找回宠物 |
| **音效** | 开启后点击/特效/里程碑播放系统提示音 |

> 所有设置（位置、大小、模式、速度、好感度、透明度、换装、皮肤、行为开关、统计）都会在**退出时**保存，并且运行期间**每 60 秒自动保存一次**，下次启动恢复。

## 换装与皮肤

### 换装换色（无需额外素材）
右键 →「换装换色」提供 7 种程序化配色：**原色 / 粉红 / 天蓝 / 紫色 / 森绿 / 橙金 / 冰蓝**。选择后即时生效并自动保存。

### 多皮肤（`assets/skins/*/`）
把角色素材放到 `assets/skins/<皮肤名>/` 下即可成为一套皮肤，右键 →「皮肤」一键切换。皮肤目录内缺失的素材会自动回退到默认素材。运行 `python generate_skins.py` 可生成 `pink` / `blue` / `gold` 三套示例皮肤（需要 Python + Pillow）。

## 东方幻存神签

右键 →「幻存神签」会弹出窗口，显示当天的官方御神签图片（角色名 + 运势），每天固定一支。

- 图片来源：[东方幻存神签/御神签速览（THBWiki）](https://thbwiki.cc/%E4%B8%9C%E6%96%B9%E5%B9%BB%E5%AD%98%E7%A5%9E%E7%AD%BE/%E5%BE%A1%E7%A5%9E%E7%AD%BE%E9%80%9F%E8%A7%88)
- 图片需先用脚本爬取到本地 `assets/omikuji/`：

```bash
python crawl_omikuji.py
```

- 脚本会抓取全部角色的御神签图片并生成 `assets/omikuji/manifest.txt`（格式：`文件名|角色|运势`）。
- 若未爬取，菜单项会提示缺失资源。

## 自定义素材

替换 `assets/` 下同名文件即可：

| 文件 | 用途 |
|---|---|
| `sprite_idle.png/.gif` | 站立/空闲 |
| `sprite_blink.png/.gif` | 眨眼 |
| `sprite_walk1.png/.gif` | 走路帧1 |
| `sprite_walk2.png/.gif` | 走路帧2 |
| `sprite_sit.png/.gif` | 坐下 |
| `stand.gif` | GIF模式站立 |
| `creep.gif` | GIF模式行走 |
| `triggers/*.png/.gif` | 右键触发特效 |

- `.gif` 优先于 `.png` 加载
- 推荐 128×128 以上带透明通道的素材
- 程序自动缩放适配窗口

## 项目结构

```
deskpet-code-with-Qt/
├── CMakeLists.txt           # CMake 构建配置
├── main.cpp                 # 程序入口
├── petwindow.h/cpp          # 宠物窗口：透明渲染 + 动画状态机 + 交互
├── pet_state.h              # 配置常量 + 状态枚举 + 好感度对话
├── sprite_loader.h/cpp      # 精灵加载器：PNG/GIF → QPixmap/QMovie
├── generate_sprites.py      # 默认精灵生成脚本（可选）
├── generate_skins.py        # 示例皮肤生成脚本（可选）
├── crawl_omikuji.py         # 幻存神签图片爬取脚本（可选）
├── assets/                  # 精灵素材（替换此目录自定义角色）
├── assets/skins/            # 自定义皮肤目录（可选）
└── assets/omikuji/          # 幻存神签图片（crawl_omikuji.py 生成）
```
